# 🚢 Titanic Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python and popular data analysis libraries.

The objective is to explore passenger demographics, identify survival patterns, detect missing values, analyze relationships between variables, and generate meaningful insights through statistical analysis and visualizations.

---

## 🎯 Objectives

- Understand the structure of the dataset
- Identify missing values and data quality issues
- Analyze passenger survival patterns
- Explore relationships between age, fare, gender, and passenger class
- Generate visual insights using charts and plots
- Summarize key findings from the dataset

---

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Dataset Used: Titanic Dataset

## 📊 Analysis Performed

- Missing value analysis

### Visualizations

- Age Distribution
- Fare Distribution

---

## 🔍 Key Findings

- The dataset contains 891 passenger records and 12 features.
- Missing values were found mainly in Age, Cabin, and Embarked columns.
- More passengers died than survived.
- Female passengers had significantly higher survival rates than male passengers.
- Most passengers traveled in Third Class.
- Most passengers were between 20 and 40 years old.
- Fare distribution was highly skewed with several outliers.
- Passenger Class and Fare showed a strong relationship.
- Survival was influenced by gender, passenger class, and fare.

---

## 📈 Conclusion

The Exploratory Data Analysis of the Titanic dataset revealed important patterns related to passenger survival. Gender, passenger class, and fare were found to be major factors influencing survival outcomes. EDA helped uncover trends, relationships, missing values, and outliers, demonstrating the value of data visualization and statistical exploration in understanding real-world datasets.
